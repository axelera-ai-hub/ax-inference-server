# Support

> ⚠️ **`ax_inference_server` (Axelera Inference Server) is an experimental reference implementation — not an Axelera product.** It is provided **as-is**, with **no service-level agreement (SLA)**, no warranty, and **no guarantee of support, maintenance, or bug fixes** from Axelera AI. Any assistance is offered on a **best-effort basis only**.

Please read this before you ask for help.

## What "best-effort" means

* There is **no SLA** and **no committed response or resolution time**. Maintainers may answer questions and pull requests slowly, or not at all.
* No Axelera commercial support contract or product warranty covers this project. Axelera hardware or a Voyager SDK license does **not** entitle you to support for this repository.
* APIs, packages, the gRPC contract, the REST control plane, the GUI and behavior **may change or break without notice**.
* Maintainers may close issues or pull requests that are out of scope for a reference implementation, without further action.

Use this project as a **starting point and reference** for your own inference server and application development. Do not use it as production code that you expect to be supported.

## Getting help

Do these two things first:

1. **Read the documentation.** Start with the [README](README.md). Then read [`server/QUICKSTART.md`](server/QUICKSTART.md) and [`client/QUICKSTART.md`](client/QUICKSTART.md) for setup. The [client examples](client/examples/README.md) hold scripts you can run. The full docs are in [`server/docs/`](server/docs/) and [`client/docs/`](client/docs/).
2. **Search the [Axelera developer community](https://community.axelera.ai/).** Someone may have answered your question already.

## Where to ask

**Post bugs, questions, ideas and usage questions about this reference implementation on the [Axelera developer community](https://community.axelera.ai/).** Include a clear description, the steps to reproduce, relevant logs and your environment. The environment means your OS, your Voyager SDK version, your Metis hardware and number of devices, and whether the problem is on the server or the client side.

| Topic | Where |
|-------|-------|
| Bugs, questions, ideas and usage help for this repo | [Axelera developer community](https://community.axelera.ai/) |
| Security vulnerabilities | **Do not** post publicly. See [Reporting security issues](CONTRIBUTING.md#reporting-security-issues). |
| Axelera **product / hardware / Voyager SDK** questions | [Axelera developer community](https://community.axelera.ai/) and [Axelera Support Portal](https://support.axelera.ai) |
